# План двух обучающих сессий (ТЗ §10)

Две живые встречи по 1,5 часа. Между ними — неделя самостоятельной работы на staging.

---

## Сессия 1 — «Базовый сценарий» (90 минут)

**Цель.** Каждый участник смог самостоятельно: войти, добавить клиента, завести вакансию, добавить кандидата, прикрепить, перевести по канбану.

| Время  | Что                                                                              |
|--------|----------------------------------------------------------------------------------|
| 0–10   | Знакомство, что такое CRM-LG (1 слайд: «зачем», «откуда брали ТЗ»).               |
| 10–20  | Демо: первый вход → смена пароля → обзор интерфейса. Роли в системе.              |
| 20–35  | **Упражнение 1.** Каждый создаёт клиента с двумя юр.лицами + контактом.            |
| 35–55  | Демо: вакансии и канбан. Правила переходов. Комментарий для финального статуса.   |
| 55–70  | **Упражнение 2.** Каждый создаёт вакансию у своего клиента, ведёт от «Новая» до «На интервью». |
| 70–85  | Демо: кандидаты, резюме, распознавание из PDF. Прикрепление к вакансии.           |
| 85–90  | Q&A, домашка на неделю.                                                          |

**Домашка.** До следующей сессии каждый ведёт минимум 3 вакансии и 5 кандидатов в реальном режиме (это про staging, не прод). Записывает вопросы и баги.

---

## Сессия 2 — «Уверенный пользователь» (90 минут)

**Цель.** Снять блокеры, обучить углублённым функциям.

| Время  | Что                                                                              |
|--------|----------------------------------------------------------------------------------|
| 0–15   | Разбор вопросов с прошлой недели — типичные сложности (Hands-on).                 |
| 15–30  | База кандидатов vs канбан. Архив / restore / permanent delete. Дубль-чек.         |
| 30–45  | Комментарии и упоминания. Уведомления (колокольчик).                              |
| 45–60  | **Упражнение 3.** Передать вакансию между рекрутерами (recruiterIds), обсудить в комментариях с @-упоминанием. |
| 60–75  | Аналитика и фильтры. Сохранённые фильтры (когда появятся, этап 9).                |
| 75–85  | Аудит-лог (для админа): что фиксируется, как разбирать вопросы «кто это поменял». |
| 85–90  | Подведение итогов, дальнейшая поддержка.                                          |
