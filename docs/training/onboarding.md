# CRM «ЛГ Интеграция» — гайд для нового сотрудника

Это короткий пошаговый сценарий. Если вы только что получили временный пароль — двигайтесь от первого пункта вниз.

## 1. Первый вход

1. Откройте `https://crm.lg.ru` (или адрес staging).
2. Email — корпоративный, пароль — тот, что вам выдал админ.
3. После входа сразу зайдите в **Профиль → Сменить пароль**. Используйте не менее 12 символов.
4. Если у вас включена 2FA (только для админов на этапе 9) — введите код из приложения-аутентификатора.

## 3. Первый клиент

1. **Клиенты → Добавить клиента**.
2. Заполните: название, отрасль, ответственный аккаунт-менеджер, тип (прямой / посредник).
3. Добавьте юр.лица (можно несколько — кнопка «+ ИНН»).
4. Сохраните. Откройте карточку → **+ контакт** для добавления ЛПР/HRD/PM.

## 4. Первая вакансия

1. **Вакансии → Создать вакансию**, выберите клиента из списка.
2. Можно вставить сплошной текст брифа в поле «Распознать из текста» — система разберёт его в поля (на staging этот эндпоинт ещё на моках — после Этапа 9 будет реальный AI).
3. Тип сделки (`engagementType`): outstaff или agency — важно, потом нельзя будет прикрепить кандидата другого типа.
4. Назначьте рекрутера через «+рекрутер».

## 5. Канбан вакансий

- Перетаскивайте карточки между колонками. **Запрещено** напрямую кидать в «Закрыта»/«Закрыта успешно» — система потребует комментарий, его задаёте через кнопку «Сменить статус» в карточке.
- Возможные переходы видно по списку всплывающих опций. Терминальные статусы: «Закрыта успешно» (бесповоротно), «Закрыта» (можно переоткрыть в «В работе»).

## 6. Кандидат

1. **Кандидаты → Добавить кандидата**.
2. Заполните контактные данные и рейт (если есть права).
3. Можно прокачать карточку резюме: **+ блок** (опыт, образование, языки, сертификаты).
4. Альтернатива: «Распознать из файла» — загрузить PDF (формат hh.ru). Парсер вытащит поля.

## 7. Прикрепление кандидата к вакансии

1. В карточке вакансии → **+ Кандидат**.
2. Выберите из базы или создайте нового. Тип сделки должен совпасть с вакансией.
3. Статусы matching'а независимы от статусов вакансии и кандидата (см. cheatsheet).

## 8. База кандидатов vs Канбан

- **Канбан** показывает активных кандидатов на доске. Когда работа окончена / кандидат «вне процесса» — нажмите **«Убрать с доски»**: он попадает в архив, но остаётся в базе.
- **База кандидатов** (`/database`) показывает всех, включая архивных. Из базы можно вернуть на доску (Restore) или полностью удалить (только админ).

## 9. Уведомления

- Колокольчик справа сверху — последние 200 событий: прикрепления, смены статусов, упоминания.
- При смене статуса вашей вакансии или кандидата вы получите уведомление автоматически.
- Email/Telegram — на этапе 9 (пока только in-app).

## 10. Аналитика

`Дашборд` показывает:
- открытые вакансии / активные кандидаты — сейчас;
- закрыто в этом месяце / нанято в этом месяце — с дельтой к прошлому месяцу;
- воронку по статусам вакансий;
- нагрузку рекрутеров (active count).

## Куда смотреть, если что-то пошло не так

- Ошибка в форме — система покажет красным конкретное поле.
- 401 «Не авторизованы» — обновите страницу, заново залогиньтесь.
- 403 «Нет прав» — у вашей роли нет этого действия (см. таблицу).
- Что-то непонятное — напишите в Telegram-чат поддержки.
