# Candidate Capture — расширение для hh.ru

Добавляет плавающую кнопку **«Сохранить резюме»** на страницах резюме hh.ru. По клику кандидат моментально попадает в подключённый рекрутинговый сервис.

URL бэка захардкожен — расширение работает только с конкретным экземпляром сервера. Установка посторонним без валидного API-токена ничего не даёт: сервер вернёт 401.

## Установка (Chrome Web Store)

После публикации сотрудники ставят расширение из Web Store, открывают попап, вставляют выданный администратором токен — готово.

## Установка (dev / до публикации)

1. `chrome://extensions/` → включить **Режим разработчика**
2. **Загрузить распакованное** → выбрать папку `extension/`
3. В CRM зайти в **Настройки → Расширение для hh.ru → Выпустить токен** → скопировать `lg_…`
4. Кликнуть по иконке расширения → вставить токен → **Сохранить** → **Проверить**

## Использование

Открыть резюме на hh.ru (URL `https://hh.ru/resume/<id>`). В правом нижнем углу — синяя кнопка **«Сохранить резюме»**. Один клик — кандидат в базе.

## Структура

```
manifest.json   — manifest v3, content script для hh.ru/resume/*
background.js   — service worker, fetch к захардкоженному API
content.js      — DOM-вставка кнопки + toast
content.css     — стили кнопки/toast
popup.html/js   — поле API-токена + кнопка «Проверить»
icons/          — 16/48/128 PNG
```

## Лимит просмотров hh.ru

`GET /resumes/{id}` ограничен квотой работодательского тарифа hh (обычно 100–500/день). При 429 показывается toast с ошибкой.
